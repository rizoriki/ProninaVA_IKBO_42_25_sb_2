# Визуализатор графа зависимостей (Вариант 24)

## 1. Общее описание
CLI-инструмент для визуализации графа зависимостей пакетов .NET (NuGet).
Построение графа выполняется алгоритмом BFS с рекурсией.

## 2. Описание функций и настроек
Параметры:
- `--package`: имя анализируемого пакета (обязательно)
- `--repo`: URL репозитория или путь к тестовому JSON (обязательно)
- `--test-mode`: режим работы с тестовым репозиторием
- `--output`: имя файла с изображением графа (по умолчанию graph.png)
- `--ascii-tree`: вывод зависимостей в виде ASCII-дерева
- `--max-depth`: максимальная глубина анализа (по умолчанию 10)
- `--filter`: подстрока для фильтрации пакетов

## 3. Команды для сборки и запуска тестов
```bash
chmod +x run.sh tests/run_tests.sh
./run.sh --package A --repo tests/test_repo.json --test-mode --ascii-tree
./tests/run_tests.sh
